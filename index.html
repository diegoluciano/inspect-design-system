Rules

Outline only, 2 px stroke, rounded caps. Green on dark surfaces, white on Ink app bars, Alert only for failed or empty states. Keep 24 dp glyphs inside a 32 dp touch frame.

06 / Tokens & accessibility

Tokens in code, contrast on paper.

:root {
  /* color · core */
  --ins-ink-900: #241D46;      --ins-indigo-700: #3B326C;
  --ins-haze-500: #6F6A8C;    --ins-mist-300: #D5D5D7;
  --ins-lav-100: #E2E2F2;
  --ins-green-500: #5AE770;  --ins-green-600: #36D57B;
  --ins-blue-500: #3398FE;    --ins-blue-700: #2273A9;
  --ins-blue-800: #2B5397;   --ins-haze-700: #544E73;   /* small text + links */
  --ins-red-500: #FF6666;

  /* type */
  --ins-font: "Cairo", system-ui, sans-serif;

  /* space · 4 pt grid */
  --ins-space-1: 4px;  --ins-space-2: 8px;  --ins-space-3: 12px;
  --ins-space-4: 16px; --ins-space-6: 24px; --ins-space-8: 32px;

  /* shape */
  --ins-radius-sm: 4px; --ins-radius-md: 12px;
  --ins-radius-lg: 20px; --ins-radius-pill: 999px;
  --ins-shadow-card: 0 6px 18px rgba(36,29,70,.14);
}
What the audit changed. The original labelled the green and red buttons in white (1.6:1 and 2.9:1). The system sets the label in Ink instead — 9.8:1 on green, 5.5:1 on red — and keeps every hue untouched. Small text moves to Haze 700 and links to Blue 800 (≥ 4.5:1).
